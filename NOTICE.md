# Права и использование

## Роман

«Аэропорт» (Airport, 1968) написан Артуром Хейли; права на текст, перевод и производные произведения принадлежат правообладателям. В материалах проекта роман не воспроизводится: используются короткие цитаты (одна-две фразы на кейс) и пересказ ситуаций в учебных целях — для разбора управленческих решений на встречах книжного клуба. Цитаты не заменяют книгу: для чтения приобретайте легальное издание.

## Иллюстрации

Карточки героев и обложка главной сгенерированы моделью Kandinsky для этого проекта в стилистике комиксов 1970-х. Это художественная интерпретация вымышленных персонажей, а не их канонические изображения; права на образы персонажей романа сохраняются за правообладателями.

## Аналитические материалы

Тексты кейсов, «личных дел», контекстных блоков и вопросы для обсуждения составлены авторами проекта. Их можно использовать и адаптировать для некоммерческих образовательных целей с указанием источника (ссылка на репозиторий). Для коммерческого использования — по согласованию с авторами.
